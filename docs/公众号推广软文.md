## 正文

### 你有没有撞上这堵墙

用 Telegram 的人，迟早会撞上一堵墙。

你关注了几十个资讯频道、几个资源群、几个行业交流群，收藏夹越攒越厚。直到某一天，你看到一个很想关注的频道，点「加入」——弹出一句冷冰冰的提示：**你已达上限**。

Telegram 免费账号能加入的**频道 + 群组合计上限是 500 个**（官方数字，Premium 会员翻倍到 1000 个）。也就是说，你每想关注一个新群，就必须先退掉一个旧的。

而这里有个非常不合理的设计：

**官方把「加入」做得极其顺手，却完全没打算帮你「退出」。**

Telegram 的桌面端和手机端，都没有多选、没有批量退出。你只能：长按群名 → 选择退出 → 二次确认 → 回到列表 → 找到下一个 → 再来一遍。500 个群，就是 500 次重复动作。手会累，心更累。

### 更麻烦的是：你根本不知道该退哪些

假设你终于下定决心要清理了，打开列表一看——傻眼。

满屏只有**频道名字**。你看不出这个是 200 人的死群还是 10 万人的大群，看不出它上次更新是昨天还是三年前，看不出它是你每天都看的干货号还是当初手滑点进去的广告群。

想搞清楚？只能一个个点进去看。500 个，点到明天。

于是绝大多数人的处理方式是：**不清理了，去开会员吧**。Telegram Premium 月费约 4.99 美元，确实能把上限从 500 提到 1000。

但说实话——为了腾出位置去关注几个新群，就为一个你一年用不上几次的「数字上限」付月费，这笔账怎么算都不划算。**你真正需要的不是更大的仓库，而是一个能快速清仓的工具。**

### 所以我写了这个工具

**TG 频道批量退出工具**，一个单文件的 Windows 桌面程序（绿色，免安装，双击即用）。

它要解决的就是上面那两件事：**让你看清楚该退哪些，然后一次退干净。**

**一、把全部订阅一次性摊开给你看**

连接你自己的账号后，工具会分页拉取**账号里的全部会话**，直接铺成一张表：

| 名称 | 用户名 | 类型 | 用户数 | 作品数 | 活跃(天前) | 分组 | ID | 安全 |
| -- | --- | -- | --- | --- | ------ | -- | -- | -- |

注意这里不是「已订阅的频道和群组」，而是**全部会话**——频道、超级群、普通群、私聊、机器人，一个不落，而且每一行都标明**类型**。

- **分页加载**：即使你有 500 个订阅，也是边拉边显示，不会卡在那儿转圈
- **表头点一下就能排序**：用户数从大到小，活跃天数从多到少，一目了然
- **一眼分辨死活**：几千人的大群和 200 人的僵尸群，排在表里高下立判
- **「活跃(天前)」是新增的关键一列**：它显示这个会话最后一条消息是几天前发的。**「180 天没说过话」比「只有 200 人」更能说明它该走了**

**二、把「该退什么」变成一道可以算的题**

工具能批量获取每个频道的**用户数**和**作品数**（消息总数）：

- **并发请求**、可调并发数，500 个频道几分钟跑完
- **本地缓存**：取到的数据存在本地，可以设置缓存有效期（默认 24 小时）。下次打开直接秒出，不会重复向 Telegram 发请求——这一点很重要，既省时间也降低被限流的概率
- **快捷筛选**：内置「用户数 < 10 / 50 / 100」「作品数 < 10 / 50 / 100」「活跃 > 30 / 90 / 180 / 365 天没消息」等 16 种预设，也可以自己填条件。**一键就能筛出「人少、又长久没更新」的那批死群**
- 支持**搜索**（名称 / 用户名）、**按类型筛**（频道 / 群组 / 私聊 / 机器人 / 已不在）、**按分组筛**、**只看已勾选**、**隐藏受保护项**

**三、真能分批清理，连 Telegram 藏起来的两类也管**

除了「退出」，工具还补上了官方客户端完全没提供的两类删除：

**① 删除会话（含聊天记录）**

对**任何类型**都适用——连私聊和机器人都能删。它只清掉**你这边**的会话与聊天记录，对方和其他成员完全不受影响。

这里要诚实提醒一句：**对频道和群组，「删除会话」只是本地隐藏。** 你仍然是成员，对方再发消息，这个会话就会重新冒出来。想彻底不再看到它，得用「退出」。工具会在日志里明确告诉你这件事，不让你产生「已经退掉了」的错觉。

**② 删除自己创建的群组 / 频道（彻底、不可恢复）**

这是很多人的真实困境：**你不小心建了几个群，现在想删掉——但你是创建者，Telegram 不允许你退出。** 于是这几个群就永远挂在那儿，占着你的 500 个名额。

这个工具能直接把它们删掉。因为这是**对所有成员生效、无法撤销**的操作，我给它设了三道闸：

1. **类型必须匹配**：菜单里「删除我创建的频道」和「删除我创建的群组」是两个独立入口，点频道就只处理频道，不会把群一起带走
2. **必须确认你是创建者**：不是创建者的一律跳过，并在清单里写明跳过原因
3. **确认窗里必须手打「删除」两个字**：输入正确之前，「确认删除」按钮一直是灰的。这个校验**没有开关可以关掉**

**四、顺手把「文件夹」也纳入管理**

Telegram 的文件夹（分组）是个好东西，但客户端里只能一个个往里拖。这个工具能：

- **「分组」列直接告诉你每个会话属于哪些分组**（可以同时属于多个）
- **按分组筛选**，一键圈出某个分组的全部会话
- 勾选后**批量加入 / 移出**某个分组——只改归属，不退出也不删除
- **自动复现 Telegram 的分组匹配规则**（群组 / 频道 / 机器人 / 联系人，以及「排除已读」「排除静音」「排除已归档」）。这一点很关键：Telegram 的分组不完全是手工列表，很多会话是**靠规则自动进来的**。只认手工加进去的那批，你会看到一堆明明在分组里、工具却显示「未分组」的会话

**五、真的能批量退，而不是假装能**

- **全选 / 反选 / 清空**，还可以「应用筛选并全选」——按条件筛出来直接全选，一步到位
- **按关键词批量退**：名称或用户名包含关键词就匹配，逗号或空格分隔多个词。比如你当初关注了一堆同类资源群，现在不想留了，输一个词就能全部选中
- **退出间隔 + 随机抖动**：默认每个间隔 2 秒，可再加一段随机等待。这是防限流的关键——批量操作最怕的就是被 Telegram 判定为异常行为
- **触发限流自动处理**：如果 Telegram 返回 FloodWait（要求等待 N 秒），工具会自动等待并重试，不需要你盯着

**六、三道安全防护，避免白跑和误伤**

批量操作最怕两件事：**删掉不该删的**，和**删一堆却全失败**。这个工具都考虑到了：

- **白名单**：把会话加进白名单，它就**永不会被退出、也不会被删除会话**（哪怕你手滑全选了）。按 ID 记录，刷新列表、重启程序都不会丢
- **自动跳过创建者和管理员**：这是一个很多人踩过的坑——**如果你在某个频道里是管理员，Telegram 根本不允许你退出**。不加判断就直接批量退，结果就是白跑一轮、报一堆错。这个工具会在获取统计时顺带识别你的身份，退的时候自动跳过，并在「安全」列标出来
- **执行前预览清单**：点退出 / 删除后先弹一个清单，分成「将执行」和「已跳过」两个页签，每一项被跳过的**原因都写在清单里**，确认无误再执行

**七、还有这些顺手的地方**

- **导出 CSV**：当前显示的行 / 全部（含被隐藏的）/ 仅已勾选，三种范围随你选。清理前先存档，心里有底
- **运行日志**：每一步都有记录，哪个成功、哪个失败、为什么失败，清清楚楚
- **代理支持**：SOCKS5 / SOCKS4 / HTTP 都行，内置「测试代理」按钮会真的试着连一次 Telegram，确认通不通。国内网络基本是必需品
- **深色模式 / 记住窗口布局 / 快捷键**（Ctrl+F 搜索、Ctrl+A 全选、空格勾选、F5 刷新）

### 怎么用（四步）

1. **拿到自己的 API 凭据**：打开 `my.telegram.org`，登录后进「API development tools」创建一个应用，得到 `api_id` 和 `api_hash`。这是 Telegram 官方给开发者用的接口凭据，**每个人用自己的，工具不会上传到任何服务器**
2. **登录**：把 `api_id` / `api_hash` / 手机号填进工具，点「连接 / 登录」，输入手机收到的验证码（开了两步验证的再输一次密码）。登录态保存在本地文件里，下次打开自动连
3. **看数据、做筛选**：等列表加载完（会自动开始获取统计），然后按用户数、作品数、活跃天数排序或筛选，挑出要清理的那批
4. **勾选、预览、执行**：勾完点「退出选中频道」或「删除 ▾」，看一眼清单，确认执行

全程本地运行，工具**不依赖任何第三方服务器**，你的账号数据不会离开你的电脑。

### 几句实话

- **只用于管理你自己的账号**。不要用它去操作别人的账号，也请遵守 Telegram 的服务条款。
- **Telegram 有风控**。批量操作天然有被限流的风险，**建议把间隔设置在 2 秒以上**，不要贪快。工具已经做了随机抖动和限流自动等待，但没有任何工具能保证 100% 不被限流。
- **删除会话 ≠ 退出。** 对频道和群组，删除会话只是本地隐藏，你仍然是成员。想真正不再看到它，用「退出」。
- **删除自己创建的频道/群组是不可恢复的**，会从所有成员那里消失。工具做了类型校验、创建者校验和手打确认词三道闸，但最终按下去的是你，请务必看清单。
- 目前是 **Windows 版本**，绿色单文件，不需要装 Python。
