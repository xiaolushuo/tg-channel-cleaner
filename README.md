# TG 频道批量退出工具

> 一个单文件的 Windows 桌面工具：把已订阅的 Telegram 频道 / 群组一次性列出来，看清用户数与作品数，勾选后批量退出。
> 纯本地运行，不依赖任何第三方服务器。

Telegram 免费账号能加入的**频道 + 群组**上限是 **500** 个（Premium 会员为 1000）。但官方客户端**没有多选、没有批量退出**，也没有任何方式让你在列表里分辨哪个是几万人的大群、哪个是 200 人的僵尸群。这个工具就是补上这块。

## 功能

**列表与数据**

- 分页加载全部已订阅频道 / 群组（几百个也不卡）
- 列：名称 / 用户名 / 类型 / 用户数 / 作品数 / ID / 安全
- 点表头排序；批量获取**用户数**与**作品数**（消息总数），支持并发数与本地缓存（默认 24 小时）
- 导出 CSV：当前显示 / 全部 / 仅已勾选

**搜索与筛选**

- 搜索：按名称 / 用户名匹配
- 类型筛选：只看频道 / 只看群组
- 快捷筛选预设（各条件之间是「且」）：用户数 < 10 / 50 / 100，作品数 < 10 / 50 / 100，以及组合条件；也支持自定义
- 「应用筛选并全选」一步到位；「只看已勾选」快速复核

**退出**

- 全选 / 反选 / 清空全部；勾选只作用于当前显示的行，被筛选隐藏的勾选项会单独提示
- **按关键词批量退**：名称或用户名包含任一关键词即匹配，逗号或空格分隔
- 退出间隔（默认 2 秒）+ 随机抖动
- 触发 FloodWait 时自动等待并重试

**安全防护**

- **白名单**：加入白名单的频道永不退出（按频道 ID 记录，跨刷新、跨重启保持）
- **自动识别创建者 / 管理员并跳过**：这两类身份在 Telegram 里无法退出，提前识别避免白跑一轮
- **退出前预览清单**：分「将退出」/「已跳过（受保护）」两个页签，确认后执行，可关闭

**其他**

- 代理支持：SOCKS5 / SOCKS4 / HTTP，内置「测试代理」真实出网验证
- 深色模式、记住窗口大小 / 列宽 / 面板开合
- 运行日志（可清空 / 导出 / 自动滚动）
- 快捷键：`Ctrl+F` 搜索、`Ctrl+A` 全选、`空格` 勾选、`F5` 刷新、`Esc` 清搜索

## 下载使用

**方式一（推荐）**：到 [Releases](https://github.com/xiaolushuo/tg-channel-cleaner/releases/latest) 下载 `TG-Channel-Cleaner-v1.0.0.exe`。

**方式二**：直接下载仓库里的 `dist/TG频道批量退出工具.exe`（两者是同一个文件）。

双击运行即可。**Windows，绿色单文件，不需要安装 Python。**

## 使用步骤

1. **获取 API 凭据**：打开 <https://my.telegram.org>，登录后在「API development tools」创建一个应用，得到 `api_id` 与 `api_hash`。
2. **登录**：填入工具，点「连接 / 登录」，输入手机验证码（开了两步验证再输密码）。登录态保存在程序目录的 `tg_session.session`。
3. **获取统计**：点「获取 / 更新统计」，等待用户数与作品数回填。
4. **筛选、勾选、退出**：按需排序筛选 → 勾选 → 点「退出选中频道」→ 确认清单。

## 数据文件

程序会把以下文件写在**自己所在目录**，请勿分享或上传：

| 文件 | 内容 |
|---|---|
| `tg_session.session` | 登录态，**等同于账号凭证** |
| `tg_cleaner_config.json` | 配置，含 `api_id` / `api_hash` / 手机号 |
| `tg_stats_cache.json` | 用户数 / 作品数缓存 |
| `tg_role_cache.json` | 创建者 / 管理员识别结果缓存 |

> 切换账号：设置栏「账号」页 → 「删除登录态（切换账号）」。

## 注意事项

- 本工具**仅用于管理你自己的账号**，请遵守 Telegram 服务条款。
- 批量操作可能触发 Telegram 风控。**建议退出间隔设置在 2 秒以上**。工具已实现随机抖动与 FloodWait 自动等待，但无法保证 100% 不被限流。
- **创建者 / 管理员无法退出频道**，这是 Telegram 的限制：创建者需先转让频道或删除频道。
- 需要代理才能访问 Telegram 的网络环境下，请先在「网络」页配置并测试代理。
